# 팀 주간 진행 보고서

입력은 한 주의 업무 기록이다. 결과는 팀의 완료 기준과 위험 분류를 적용한 Markdown 보고서다. 상태 이름만 보고 완료 여부를 결정하지 않는다.

보고서를 작성할 때 [팀 규칙](references/team-rules.md)을 읽는다. 이 문서에 데이터 필드, 분류 우선순위, 기한 계산, 보고서 형식이 있다. 현재 팀 규칙을 새로 추측하거나 일반적인 프로젝트 관리 기준으로 바꾸지 않는다.

사용자가 준 JSON이나 파일이 있으면 그것을 사용한다. 연결된 `get_weekly_records`로 조회해도 된다. MCP 연결은 필수가 아니며, 보고서를 쓰기 위해 새 서버 설치나 계정 인증을 시작할 필요는 없다. 대상 주차를 알 수 없으면 주차를 확인한다.

입력의 `report_date`를 기준으로 각 기록을 한 번씩 분류한다. 보고서에는 업무 ID와 판정의 근거가 된 필드를 남긴다. 팀 규칙으로 판정할 수 없거나 기록이 충돌하면 위험 항목으로 분리하고 확인이 필요한 사실을 적는다.

보고서를 파일로 요청받으면 Markdown으로 저장한다. 이 Skill은 기록 자체를 고치거나 메시지를 발송하지 않는다. 사용자가 규칙 변경을 요청하면 해당 요청의 기준을 우선하고 보고서에 달라진 기준을 표시한다.
